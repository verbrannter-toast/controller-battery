This is a plugin for [caelestia-kde](https://github.com/ladybug-me/caelestia-kde) to show the battery level of PS5, Steam or any other controllers. 

<img width="3840" height="2160" alt="image" src="https://github.com/user-attachments/assets/5b3814e8-f4d0-4b79-841b-bfe166140e73" />

It is movable across the whole desktop and saves its position across reboots. When just one or no controller is connected it simply resizes or hides completely.

## Important note
I made the svg icons for both the PS5 and Steam controller myself but since they depict the product design copyrighted by Sony/Valve this is only to be used for personal reasons.
